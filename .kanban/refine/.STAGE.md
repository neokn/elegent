# refine

A card in refine/done/ is one story the Problem Owner has accepted.

## Do
Run the `refine` skill with the card's `description` as the requirement and
its `sources`, when it has any, as where the requirement came from, with the
person as Problem Owner. It writes one `story.md` per story it delivers.

When refine delivers **one** story, this card becomes it: record below, then
gate. When it delivers **several**, this card is the requirement and each story
is a child: allocate one child per story inside this card's hundred; create each
in `backlog/` with `parent_id`, its own record and its own gate decision; pull it
into `refine/doing/` and finish it into `refine/done/`; append a `split` event
naming the children and an `archived` event to this card and move it to
`archive/` — all in one transaction, or none of it. An absent Problem Owner leaves
this card in `refine/doing/`, unsplit. A rejected story rejects the split: this
card gets a `gate` event with verdict `rejected` naming the story, and no child
is created.

## Record
- `attempt`
- `artifacts`: the story file(s)
- `summary`: the story's title and the quality words QUPER settled
- `open_questions`: anything refine could not settle with the person

## Gate
Show the Problem Owner each story whole, its `sources` included, with its open
questions and each glossary term marked `(assumed)`. Their word is the verdict; record it. On an
approve, remove `(assumed)` from each term shown. The glossary is shared by every card, so it
does not wait for the merge: then commit it alone in the main tree,
`git commit -m "docs(<card id>): glossary" -- GLOSSARY.md`, when it changed.
