# design

A card in design/done/ has an implementation plan per specification that the
Product Developer has accepted.

## Do
Run the `solution-design` skill once per specification file the index `spec.md`
lists, never on `spec.md` itself, in the index's order, with the person.

## Record
- `attempt`
- `artifacts`: every plan, and every ADR it drafted with the ADR log
- `summary`: one line per plan, and each decision it records, with its ADR
- `open_questions`: anything solution-design could not settle with the person

## Gate
Show the Product Developer every plan whole, its `## Decisions` included, and
every `Proposed` ADR it drafted. Their word is the verdict; record it. On an
approve, mark each ADR they accept `Accepted` and remove each they reject; ADRs
bind every later change, so they do not wait for the merge: commit them alone in
the main tree, with the ADR log,
`git commit -m "docs(<card id>): ADR-<n>[, ADR-<m>]" -- <ADR files> <ADR log>`.
On a reject, remove the plan's `Proposed` ADRs and their log rows.
